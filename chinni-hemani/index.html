  • Support day-to-day AKS operations: namespaces, deployments, services, ConfigMaps and secrets, scaling, node pool health and troubleshooting failing pods.
  • Manage source control in Azure Repos, setting up branching strategies, branch policies and pull-request reviews to keep the main branch stable.
